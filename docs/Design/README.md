# Design Documents

Design documents explain how a system should behave and why. They may contain proposed approaches, implementation phases, acceptance criteria, and unresolved questions.

## Documents

- [NPC Behavior](NPC_Behavior.md) — exploration, memory, return routing, Z-depth movement, trap reactions, action feedback, and parties.
- [World Generation and Building](World_Generation_and_Building.md) — tile construction, traversal placement, room width, structures, depth planes, progression, economy, and boss rooms.

These documents are living plans. A recommendation in a design document is not a settled project decision until it is recorded in [`../Decisions/`](../Decisions/README.md).
