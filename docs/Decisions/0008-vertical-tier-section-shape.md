# 0008: Vertical Tier Section Shape

- Status: Proposed
- Date: 2026-08-09

## Context

Later progression should require unlocking deeper dungeon sections, with more building space available at deeper tiers.

## Proposal

Tier 1 starts with a section three vertical floors high. Each successive downward section is one floor taller, producing section heights of 3, 4, 5, 6, and 7 floors through Tier 5.

## Consequences

- Progression gets a clear spatial milestone at each tier.
- Total dungeon height and content demands grow quickly.
- Horizontal bounds, costs, pacing, and performance need a prototype before this is accepted.

See [Building Limits and Progression](../Design/World_Generation_and_Building.md#building-limits-and-progression).
