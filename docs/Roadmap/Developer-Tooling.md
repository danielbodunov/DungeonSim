# Developer Tooling Roadmap

## Purpose

Create practical Unity testing tools that make gameplay scenarios quick to reproduce while continuing to exercise normal production systems.

## Immediate milestone

Complete DEV001, DEV002, and DEV003 before starting t007.

- DEV001 — Generic Prop & Treasure Placement
- DEV002 — Reusable Dungeon Test Scenarios
- DEV003 — NPC Runtime Debug Harness

Later tooling may include AI visualization, decision history, scenario initial conditions, scenario assertions, and an automated scenario runner.
